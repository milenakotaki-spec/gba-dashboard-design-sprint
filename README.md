# Protótipo GBA Dashboard

Este protótipo é um site simples (HTML/CSS/JS) que qualquer pessoa pode abrir no navegador.

## Como abrir
1. Abra o arquivo `index.html` no navegador.
2. Para editar, mude textos e estilos em `index.html` e `styles.css`.

## Como colaborar com outras pessoas
Use um repositório no GitHub e peça para cada pessoa editar e enviar mudanças.
